A one-line sick-day excuse for the make.fun text bounty. `main.py` holds the
line in `ENTRY` and writes it to `$OUTPUT_DIR/entry.txt` (default `/output`),
UTF-8, no trailing newline, printing `LEN=<n>` and exiting non-zero unless the
text is non-blank and 1..200 characters.

Run:

```sh
OUTPUT_DIR=/tmp/o python3 main.py
```
